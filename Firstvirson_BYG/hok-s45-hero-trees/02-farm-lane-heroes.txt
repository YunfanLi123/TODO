王者荣耀 S45「月照长安」发育路英雄决策树

编制说明
时间节点固定为 0:00 → 2:00 → 4:00 → 6:00 → 10:00 → 12:00 之后，与《分路决策树》同一套时间轴。
每个分支由 前提 / 动作 / 后果 三部分组成，后果末尾的【状态标签】是下一节点的判断输入。
前提只写当场能在小地图、装备栏、技能栏、冷却栏上看到的事实：头像位置、塔是否已破、谁阵亡、技能是否已交、兵线位置、视野是否存在、倒计时。
动作只写该英雄技能能做到的具体操作，不写与机制无关的通用分路套话。
数据逐条标注口径：全球服 2026-10-16 官方 HoK Camp 快照、国内服排位、国内服巅峰赛、国内服顶端局，不同口径不混写；官方快照未收录的英雄只写机制与动作。
通用设置：开启显示头像与优先攻击头像，关闭自动攻击改手动，优先攻击目标设为绝对血量最少。
本次覆盖发育路英雄 22 名，原名单 23 条，伽罗重复出现一次，按一名英雄计。

========================================================
百里守约
  定位：站桩型射手，一技能放视野装置判断敌方打野动向，二技能狙击清兵有保底，三段位移用于保命，大招贯穿随命中目标数增加伤害。
  数据：巅峰赛胜率 51.5%、登场率 23.1%（国内服巅峰赛口径）；全球服胜率 49.02%、登场率 1.0%（2026-10-16 官方 HoK Camp 快照）

0:00 节点
├─ 前提：对方射手在塔前补刀且位移未交
│  动作：站位保持在自己兵线与己方塔之间，只用普攻与二技能擦到对方，不追出塔范围
│  动作：一技能视野装置放在对方塔前草丛与河道入口
│  后果：对方射手被迫回塔，视野覆盖敌方打野位置，状态【塔下补刀，视野在手】
├─ 前提：对方射手前压出塔
│  动作：立刻后撤到塔下，用二技能清掉进塔的小兵，不做换血
│  后果：血量与技能保留，状态【塔下补刀】
└─ 前提：敌方刺客两名以上且已进入我方半区
   动作：先在塔下等对方头像露出，期间只用一技能与二技能清塔前小兵
   后果：不进无视野区域，不交一血，状态【缩塔等控】
   ├─ 前提：刺客位置在河道草丛
   │  动作：一技能视野装置丢进草丛，装置照出对方时后撤一步
   │  后果：知道对方是否在草内，状态【刺客已暴露】
   └─ 前提：刺客位置未出现在小地图
      动作：缩到塔下停止压线，视野装置只放在自家塔侧
      后果：被突进时有塔保护，状态【缩塔等控】

2:00 节点
├─ 前提：【塔下补刀】+ 河道路口已有我方视野
│  动作：与打野一起进发育路与对抗路之间的河道右侧暴君坑，用二技能与普攻打龙
│  动作：龙被抢时用二技能收手，立刻回塔下
│  后果：拿到暴君 buff 或用技能换回血量，状态【打完暴君，buff 在手】
├─ 前提：【塔下补刀】+ 河道路口无视野
│  动作：把一技能视野装置插在河道入口，站在装置照不到的对侧等
│  后果：拿到河道信息，状态【河道已开视野】
├─ 前提：被对方两人夹击
│  动作：交雾行千山穿墙撤离，位移期闪避伤害，落地后不回头
│  后果：脱离战场，雾行千山进入 100 秒冷却，状态【已脱战，雾行冷却中】
└─ 前提：【缩塔等控】
   动作：只补最后一下兵，被压出塔时交一段三段位移回塔
   后果：不交一血，状态【塔下补刀】

4:00 节点
├─ 前提：【打完暴君，buff 在手】+ 己方下路外塔已破 + 敌方打野不在此路
│  动作：转线去中路吃线，顺路收红区小野，一技能装置探草丛
│  后果：把发育路时间换成中路压力，状态【已转线】
├─ 前提：己方下路外塔未破 + 塔的前期护盾已移除
│  动作：带兵线推塔，推进时留一个身位的退路
│  后果：塔血被压低，状态【塔血偏低】
├─ 前提：【河道已开视野】+ 转线路径上敌方打野头像出现在附近
│  动作：停下转线，先用一技能装置把该区域照亮
│  后果：转线不被打断，状态【转线暂停，视野已开】
└─ 前提：附近有团战 + 己方前排已与对方前排接触
   动作：站在己方前排身后，用大招对准敌方后排穿透射击
   后果：一发打穿多人，状态【已参团，站位在后排】

6:00 节点
├─ 前提：【已参团，站位在后排】+ 团战中对方先打出控制并命中己方前排
│  动作：后撤半步，等对方控制交完再从侧面输出
│  后果：避开控制窗口，状态【控制已交，输出环境成立】
├─ 前提：【已转线】+ 团战中己方前排不在场
│  动作：不进团，带线推对方边路塔
│  后果：改拿塔经济，状态【带线推塔】
├─ 前提：对方三人以上已经进入我方半区
│  动作：收线回塔，用二技能清掉塔前小兵
│  后果：不被抓单，状态【塔下收线】
└─ 前提：本局己方已阵亡两人次以上
   动作：缩塔，专心清兵线，团战只远距离点对方主输出点
   后果：减少阵亡，状态【带线补经济】

10:00 节点
├─ 前提：【控制已交，输出环境成立】+ 龙坑有我方视野 + 己方五人到位
│  动作：站龙坑侧后方输出，用二技能与普攻打暗影暴君与暗影主宰
│  动作：对方切后时交三段位移拉开
│  后果：拿到增益，状态【龙坑输出位已站住】
├─ 前提：【带线推塔】+ 龙坑无我方视野
│  动作：先用一技能装置照龙坑，不进无视野坑
│  后果：视野到手再打，状态【龙坑已开视野】
├─ 前提：敌方刺客已到我方后排位置
│  动作：闪现拉开距离，交给辅助处理
│  后果：不被近身，状态【已拉开距离】
└─ 前提：对方五人在龙坑附近
   动作：不进坑，带线拆对方边路二塔
   后果：用塔换龙，状态【带线拆塔】

12:00 之后
├─ 前提：【龙坑输出位已站住】+ 己方拿到风暴龙王
│  动作：跟在队伍侧后方推进，用大招贯穿对方前排点主输出
│  后果：推进敌方高地，状态【推进敌方高地】
├─ 前提：【龙坑已开视野】+ 对方拿到风暴龙王
│  动作：守高地塔，优先清龙兵线
│  后果：拖时间等对方失误，状态【守高地】
├─ 前提：龙未开
│  动作：占龙坑视野，等刷新
│  后果：拿到后再推进，状态【龙坑已占视野】
└─ 前提：自己被对方切
   动作：交三段位移撤，团战交给队友
   后果：不阵亡，保留技能 CD，状态【已脱离战场】

│  后果：不被近身，状态【已拉开距离】
├─ 前提：团战开打时己方前排不在场
│  动作：不进团，跃至空中射箭清线推塔
│  后果：改拿塔经济，状态【带线推塔】
└─ 前提：对方三人站在一起
   动作：把陷阱布在三人脚下，开大激活周边陷阱
   后果：狼魂围攻三人，状态【狼魂围攻中】

10:00 节点
├─ 前提：【控制已交，输出环境成立】+ 龙坑有我方视野 + 己方五人到位
│  动作：在龙坑侧后方草丛潜伏，跃至空中射箭打龙坑内目标
│  后果：拿到增益，状态【龙坑输出位已站住】
├─ 前提：【带线推塔】+ 龙坑无我方视野
│  动作：先在龙坑侧草丛潜伏观察，再进坑
│  后果：视野到手再打，状态【龙坑已开视野】
├─ 前提：对方五人在龙坑附近
│  动作：不进坑，带线拆对方边路二塔
│  后果：用塔换龙，状态【带线拆塔】
└─ 前提：自己已能开大激活陷阱
   动作：把陷阱布在龙坑入口两侧，开大引狼魂围攻龙坑内敌人
   后果：龙坑内敌人被拉住，状态【龙坑内已被拉住】

12:00 之后
├─ 前提：【龙坑输出位已站住】+ 己方拿到风暴龙王
│  动作：跟在队伍侧后方推进，跃至空中射箭打对方后排
│  后果：推进敌方高地，状态【推进敌方高地】
├─ 前提：【龙坑已开视野】+ 对方拿到风暴龙王
│  动作：守高地塔，优先清龙兵线
│  后果：拖时间等对方失误，状态【守高地】
├─ 前提：龙未开
│  动作：占龙坑视野，等刷新
│  后果：拿到后再推进，状态【龙坑已占视野】
└─ 前提：对方前排已回位
   动作：把陷阱布在对方前排脚下，开大引狼魂缠住前排
   后果：对方前排被牵制，状态【前排已被缠住】
