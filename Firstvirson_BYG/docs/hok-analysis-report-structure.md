# 王者思路分析报告：结构规范与骨架

> 适用范围：`softbigproject` 下所有「思路 / 打法 / 决策」类分析文档
> 建立日期：2026-10-21
> 关联约定：本项目已有「攻略原文是唯一真源」约定；本文是它在**报告层**的对应物

---

## 0. 一句话结论

报告分**三层**（指向层 / 机制层 / 证据层），全篇只用**一种表达单元**（决策单元）承载「可执行指向」，
并规定**可执行指向只存在于一张总表**——正文只负责讲机制并引用单元编号。

---

## 1. 核心病灶：指向漂移

现有三份文档的内容质量没问题，真正的结构问题是**同一份知识被拆在三个地方**：

| 位置 | 承载内容 | 例 |
|---|---|---|
| 正文自然段 | 结论+条件混在叙述里 | `operations-report` §2 中期「控龙 vs 人头的本质」埋在段落末尾 |
| 章节末速查表 | 压缩版结论 | `action-timeline` §7「动作与停止条件总表」 |
| 全局清单 | 另一版措辞 | `operations-report` §7「全局高频亏损动作清单」 |

三处措辞不同 → 读者要跨段拼装 → **读完知道「局势如何」，但不知道「我现在按哪一条做」**。
这就是"指向不明确"的根源，与内容详略无关。

**解法**：决策单元**只在一张总表出现一次**，正文引用编号，不复述措辞。

---

## 2. 三层骨架

### 第 0 层｜指向层（≤1 页，必须能单独成立）

读者只看这一页就要能开始决策。

1. **一句话总览**：这版游戏的全局判断，一句话。
2. **全局结论表**：不超过 10 行，列 = `结论 | 适用条件 | 失效条件 | 档位`。
3. **速查入口**：指向各分路章节的跳转，并指向决策单元总表。

> 现有缺口：`operations-report` 没有这一层（`t0-tier-matchup-analysis` 有「一句话总览」，可作范例）。

### 第 1 层｜机制层（正文主体）

1. **版本底色**：全局判断，≤3 条，每条必须能推导出多个分路行为。
2. **分路 × 时间窗展开**：五分路 × 三时间窗 = 15 个固定格子，顺序固定不变。
3. **决策框架**：每个格子的核心判断条件。

### 第 2 层｜证据层

1. **可信度分级表**（A/B/C/D）
2. **逐条来源**
3. **待自行核对清单**：明确点名"报告说了但没验证"的地方

### 三份文档的层级关系

```
入口页（指向层，1 页）
 ├─ 主报告：分路运营模式（机制层 + 决策单元总表）
 ├─ 附录 A：行动时间轴（客观描述，事实层）
 ├─ 附录 B：英雄对位（英雄层）
 └─ 附录 C：来源分级 + 待核对清单（证据层）
```

> 现在三份文档是**平级**的，读者不知道先读哪份、重复内容以谁为准。
> 建议改成「1 主 + 3 附录」，并在入口页写明「重复时以主报告为准」。

## 3. 决策单元：让「指向」可核对

一个决策单元 = 五要素，缺一不可：

| 要素 | 含义 | 写法要求 |
|---|---|---|
| **触发条件** | 什么时候这个判断开始成立 | 可观察的战场事实，不用"局势不好"这种主观词 |
| **动作** | 具体做什么 | 动词开头，一句话，能直接执行 |
| **停止 / 放弃条件** | 什么时候不做它 | 必须有，至少一条 |
| **失败模式** | 做错会长什么样 | 具体到死法或掉点 |
| **依据档位** | A/B/C | 与全报告分级一致 |

**编号规则**：`D-<位置>-<时间窗>-<序号>`
位置 = JG 打野 / MID 中路 / TOP 对抗路 / ADC 发育路 / SUP 游走
时间窗 = E 前期(0-4') / M 中期(4-10') / L 后期(10'+)

示例：

```markdown
### D-JG-E-01　先到 4 级，再谈 gank

- 触发：开局、自身野区未清完
- 动作：清完自己野区升到 4 级
- 停止 / 放弃条件：敌方深压线 + 我方线上血量健康 + 我方控制链就绪 + 敌方关键召唤师技能进真空 —— 四条同时满足才放弃剩余小野绕后
- 失败模式：漏野导致等级滞后，失去与对方打野对拼资格（连锁亏损，非单点亏损）
- 依据：A 级（防御塔免伤、空间之灵调整提升抓人成本）
```

**模板骨架**（每个决策单元都长这样）：

```markdown
### D-<位置>-<时间窗>-<序号>　<动词开头的标题>

- 触发：<可观察事实>
- 动作：<动词开头，一句话>
- 停止 / 放弃条件：<至少一条>
- 失败模式：<具体后果>
- 依据：<A/B/C 级>（<来源摘要>）
```

## 4. 表格规范

1. **每张表独立可读**：不依赖上文的代词（"它""这条""上述"）能看懂。
2. **列顺序固定**：`条件 → 动作 → 停止条件 → 失败模式 → 档位`。
3. **决策单元总表**放在正文之后、证据层之前，是全篇唯一的"指向总入口"。
4. 表格单元格控制在 30 字内；超过就说明该写成决策单元。

---

## 5. 章节标题规范

用**判断句**，不用名词短语。

| 差 | 好 |
|---|---|
| 前期打法 | 第一目标是「到 4 级且保住野区」，不是抓人 |
| 游走位策略 | 跟着打野，别跟着射手 |
| 视野机制 | 视野从「免费信息」变成「可争夺资源」 |

判断：标题读完能独立回答"所以呢"→合格。

## 6. 写完自检清单

- [ ] 每条结论都能回答「我现在做什么」，而不是只回答「局势如何」
- [ ] 每个可执行指向都能在决策单元总表里找到唯一出处
- [ ] 每条结论都带触发条件与放弃条件
- [ ] 所有数字 / 机制改动都带档位标记
- [ ] 每张表脱离上下文也能读懂
- [ ] 章节标题是判断句
- [ ] 正文没有复述总表措辞（只引用编号）
- [ ] 没有两份文档讲同一件事且措辞不同
- [ ] 指向层单独抽出来仍成立
- [ ] 待核对点被明确点名，没有藏在正文里

## 8. 与「唯一真源」约定的呼应

项目内已确立「攻略原文是唯一真源 → 解析器 → 映射表 → 生成器」的四层链路，
报告层应遵循同一条纪律：

**攻略原文是唯一真源 → 决策单元总表是唯一指向源 → 正文只做解释。**

判据：任何一条指向，如果正文里有一处、总结表里有一处、且措辞不同，就是违反本规范。
