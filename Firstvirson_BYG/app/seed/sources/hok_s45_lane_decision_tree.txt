王者荣耀 S45「月照长安」分路决策树


══════════════════════════════════════════════════════
打野
══════════════════════════════════════════════════════

0:00 节点
├─ 前提：敌方打野为红开（已知或从预选推测）
│  动作：己方蓝开反向开局，蓝 BUFF → 蜥蜴 → 狼 → 红 BUFF → 小鸟，1:15 至 1:50 到 4 级
│  动作：33 秒进野区，进场时手里捏着惩
│  后果：避开前期野区碰撞，4 级时可直接到对抗路形成夹击，状态【野区均势】
├─ 前提：敌方打野为蓝开
│  动作：己方红开反向开局，红 BUFF → 小鸟 → 猪 → 蓝 BUFF，1:15 至 1:50 到 4 级
│  后果：同上，状态【野区均势】
├─ 前提：己方打野前期强度弱于对方
│  动作：开局方向不变，但进场前先让中单与游走把视野做出来；对方进我方野区时不接战
│        直接换到对方另一半野区
│  后果：避免被动接战导致双 BUFF 全丢，状态【野区均势】
└─ 前提：对方已进我方 BUFF 区且血量高于我方惩击可收割线
   动作：不抢 BUFF，改入侵对方同侧野区对换，或转去线上逼对方回防
   后果：资源损失由对方野区补回，等级不落后，状态【野区均势】

0:30-1:00 节点
├─ 前提：中单与游走已到位
│  动作：与中单、游走一起控中路河道之灵，中路河道之灵优先于常规野怪
│  动作：通知两条边路同步向中路集结
│  后果：拿到 1 分钟河蟹，建立前期经济与联动优势
└─ 前提：中单或游走未到位
   动作：放弃中路河道之灵，回自己野区按顺序刷野
   后果：等级正常推进，等下一次河蟹

2:00 节点
├─ 前提：【野区均势】+ 暴君已被我方击杀
│  动作：入侵对方野区，或帮线上推塔
│  后果：对方野区暴露时间变长，状态【野区领先】
├─ 前提：【野区均势，无龙 buff】+ 对方正在打暴君
│  动作：绕过龙坑进对方野区
│  后果：补回部分资源，等下一次暴君
└─ 前提：【野区劣势】
   动作：守自家野区，等敌方分散后单抓
   后果：等级追平前不进入 5v5

4:00 节点
├─ 前提：塔的早期护盾已消失 + 敌方打野不在我方半区
│  动作：带兵线推塔，推完顺路在敌方半区做视野
│  动作：推塔顺序为边路一塔 → 中路一塔与边路二塔 → 中路二塔与边路二塔 → 高地
│  后果：塔的经济到手，敌方半区视野展开
├─ 前提：暴君倒计时进入最后一段 + 龙坑有我方视野
│  动作：集合占位龙坑，惩击留到龙最后一刻再交
│  后果：拿到 buff，或逼出对方控制与位移
├─ 前提：暴君倒计时进入最后一段 + 龙坑无我方视野 + 视野精灵在龙坑附近
│  动作：抢时间差，在对方视野盲区窗口内打完
│  后果：成功则拿到 buff；被对方先手或打断则转为【野区劣势】
├─ 前提：团战中对方先打出控制并命中我方前排
│  动作：不进入，等对方控制交完打第二轮
│  后果：避开在对方控制窗口内接团
└─ 前提：全场决策
   动作：由打野做实时指挥，喊出敌方打野位置、暴君主宰倒计时、是否开团
   后果：全队在有地图信息的位置做决策

6:00 节点
├─ 前提：双方五人都在场 + 敌方有人阵亡未复活
│  动作：趁敌方人数缺失主动开团，随后控龙推塔
│  后果：以多打少，敌方减员期间无法接团
├─ 前提：双方五人都在场 + 无人阵亡
│  动作：不主动开团，以龙逼团、以塔逼团，迫使对方为争资源移动阵型后再进
│  后果：对方阵型因移动出现缺口，主动权保留在己方
├─ 前提：己方有人阵亡未复活
│  动作：不接团，清线、控龙、缩小活动范围
│  后果：避免二次减员，等队友复活
└─ 前提：己方处于落后
   动作：只刷己方安全野区，gank 己方优势路而非劣势路，放弃争不到的龙，用近侧两座塔换
         远侧资源
   后果：等对方失误翻盘，不扩大差距

10:00 节点
├─ 前提：我方先到龙坑
│  动作：开龙
│  后果：拿到主宰先锋，拆边路二塔，状态【有主宰】
├─ 前提：敌方先到龙坑
│  动作：放弃龙，转推边路塔
│  后果：塔经济到手，等下一次龙
└─ 前提：双方同时抵达、均未开龙
   动作：由打野在龙坑外埋伏，制造要开龙的假象；让游走探草确认对方后排位置
   后果：对方进坑后被包，或我方拿到视野差后再决定开或撤

12:00 之后
├─ 前提：【有主宰】
│  动作：带线拆塔
│  后果：推进敌方高地
├─ 前提：对方有主宰
│  动作：守高地塔，优先清龙兵线
│  后果：拖到队友复活
├─ 前提：对方在另一侧打龙
│  动作：不去争，去推塔或打另一个资源
│  后果：用地图压力换掉这次龙
└─ 前提：双方无主宰且己方五人齐
   动作：开龙，惩击留到最后一刻，拿到后立刻转推
   后果：等 20:00 风暴龙王


══════════════════════════════════════════════════════
中路
══════════════════════════════════════════════════════

0:00 节点
├─ 前提：1 级能先清完第一波线
│  动作：1 级先普攻后技能抢线，在兵线进对方塔前完成清线
│  动作：把兵线推进对方塔下，再移动到能观察河道草丛的位置，不退回塔下
│  动作：清兵用小额基础技能，控制与爆发技能留着
│  后果：兵线推进至对方塔下，状态【我方兵线过河】
├─ 前提：清线慢半拍
│  动作：放弃第一波线权，直接去河道占位
│  后果：兵线仍在己方塔前，状态【对方兵线过河，河道路口有视野】
└─ 前提：被对方二级抓中
   ├─ 前提：血量健康
   │  动作：交位移往己方塔下退
   │  后果：保住经验与技能
   └─ 前提：血量低于一半
      动作：直接回城
      后果：掉一层经济，保住后续发育

2:00 节点
├─ 前提：河道路口有视野
│  动作：与打野集合打暴君，首条暴君固定在发育路与对抗路之间的河道右侧
│  后果：拿到暴君 buff，状态【有龙 buff】
├─ 前提：河道路口无视野
│  动作：不进河道，清线并补河道路口视野
│  后果：视野到手，下一次暴君再集合
└─ 前提：对方已在龙坑内打暴君
   动作：转去压对方边路外塔
   后果：用塔换龙

4:00 节点
├─ 前提：已抢到线，且清完后无新兵线刷新
│  动作：清完线立刻支援，支援方向优先劣势路止损、其次优势路扩优
│  后果：抢占支援时间差，把个人线权转成团队资源
├─ 前提：已抢到线，但清完后兵线又刷新
│  动作：不去支援，留在线上清掉新兵线
│  后果：保住线权，不因空档被对方先动
├─ 前提：没抢到线
│  动作：清完线后跟在对方中路后面移动，不进无视野河道
│  后果：对方打过来时能第一时间到场救场
├─ 前提：敌方打野最后出现位置在另一半地图
│  动作：主动压对方中一塔
│  后果：压缩对方转线路径
├─ 前提：敌方打野最后出现位置在我方半区
│  动作：清线并做河道路口视野，不压塔
│  后果：保住中路不被抓
└─ 前提：敌方打野位置未知
   动作：清完线回塔下或转去己方野区做视野
   后果：保住自身，等敌方位置暴露后再压塔

6:00 节点
├─ 前提：己方兵线已推进至对方塔下
│  动作：清完线跟打野游走
│  后果：形成中野联动
├─ 前提：己方兵线还在自家塔前
│  动作：塔下清线，在己方野区做视野，帮打野反蹲
│  后果：防止对方抓单
└─ 前提：团战中对方先打出控制并命中己方前排
   动作：后撤到己方前排身后
   后果：等对方控制交完再进

10:00 节点
├─ 前提：我方先到龙坑
│  动作：开龙
│  后果：拿到暗影暴君与暗影主宰增益，主宰先锋替换兵线
├─ 前提：敌方先到龙坑
│  动作：转去压边路塔
│  后果：用塔换龙
├─ 前提：团战即将开始
│  动作：站到与敌方突进距离大于其一个突进位移加一个闪现的位置，位于队伍侧后方
│  后果：敌方刺客需要额外位移才能触达，输出环境保留
├─ 前提：对方控制与爆发技能已交 + 己方全员就位
│  动作：开大分割战场，优先框住敌方主输出点
│  后果：形成以多打少
└─ 前提：团战打输，己方有人未复活
   动作：后撤清线，不补位置
   后果：止损，保留技能

12:00 之后
├─ 前提：对方已在龙坑开风暴龙王
│  动作：守高地塔，优先清龙兵线
│  后果：拖到对方失误
├─ 前提：己方拿到风暴龙王
│  动作：推进直推水晶
│  后果：终结比赛
├─ 前提：龙未开
│  动作：占龙坑视野，等刷新
│  后果：拿到后再推进
└─ 前提：己方需要完整人数
   动作：集合，不单独进带
   后果：避免被单抓


══════════════════════════════════════════════════════
对抗路
══════════════════════════════════════════════════════

0:00 节点
├─ 前提：1 级换血后对方血量低于我方且其位移未交
│  动作：1 级抢线建立线权，2 级继续压线，逼对方交位移
│  后果：状态【对线优势】
├─ 前提：1 级换血后对方血量高于我方
│  动作：塔下补刀，等打野，不贪战
│  后果：状态【对线劣势】
└─ 前提：对方一级埋伏在我方兵线侧草丛
   动作：用技能试探草丛，或直接走线上不蹲草
   后果：不交一血

2:00 节点
├─ 前提：【对线优势】
│  动作：抢完线把兵线推到对方塔下，再往河道蟹或传送阵方向走
│  动作：走河道前确认自己这条线的兵线已过河且己方塔前无兵
│  后果：形成我方可越塔、对方不可越塔的对称差，且支援不丢线
├─ 前提：【对线劣势】
│  动作：塔下清线，在己方野区做视野
│  后果：防止对方抓单
├─ 前提：敌方三人以上出现在我方防御塔范围内
│  动作：退塔下，不交位移
│  后果：保住人头，等队友到位
└─ 前提：需要绕到敌方一塔后
   动作：绕后断对方兵线
   后果：多出 10 到 20 秒支援时间，限制对方在守塔与支援之间抉择

4:00 节点
├─ 前提：4 级且大招在手 + 敌方打野不在我方半区
│  动作：压线消耗，只求逼出对方位移与闪现，不追求换血收益
│  后果：对方关键位移已交，后续单杀与越塔可行
├─ 前提：敌方打野在我方半区
│  动作：回塔下，放弃压线
│  后果：保住血量与技能
├─ 前提：传送阵已激活，图标出现在小地图 + 队友在另一侧
│  动作：交传送支援
│  后果：形成夹击
├─ 前提：想补经济去中路
│  ├─ 前提：中路有人且正在赶回
│  │  动作：不独自去中路吃线
│  │  后果：不因落单被打断节奏
│  └─ 前提：中路阵亡或赶不回来
│     动作：去中路吃线
│     后果：补上中路的空档
└─ 前提：对方关键控制未交 + 己方队友未全员就位
   动作：不开团
   后果：不在对方控制窗口内接团

6:00 节点
├─ 前提：敌方五人位置集中 + 己方打野位置可确认
│  动作：参团，等对方控制交完再进场；坦边开团后第一动作是回防保护己方射手
│  后果：以多打少，且己方射手不被切
├─ 前提：敌方五人位置集中 + 己方打野位置无法确认
│  动作：不参团，继续带线
│  后果：避免被以多打少
├─ 前提：敌方分散在各线
│  动作：带线牵制
│  后果：逼对方回防
└─ 前提：带线时敌方 2 至 3 人出现在我方兵线前方
   动作：交位移撤离
   后果：放弃该线，等级不落后

10:00 节点
├─ 前提：敌方五人集中在龙坑
│  动作：不进龙坑，带线拆对方二塔或高地外塔
│  后果：正面形成以多打少，或对方被迫回防分人
├─ 前提：敌方分散
│  动作：带线牵制，优先边路二塔
│  后果：逼对方回防
└─ 前提：自己被对方切
   动作：交位移撤，团战交给队友
   后果：不阵亡，保留技能 CD

12:00 之后
├─ 前提：视野精灵仍在边线附近
│  动作：先清掉或驱离，再推线
│  后果：避免被照出后被包
├─ 前提：视野精灵已清除 + 己方主力在对面 + 己方需要完整人数
│  动作：不深推孤线，回队伍集合
│  后果：保留人数优势
├─ 前提：视野精灵已清除 + 己方主力在对面 + 己方已能稳守高地
│  动作：深推最远边线
│  后果：换到塔的经济
└─ 前提：己方需要回防
   动作：留在队伍中间威慑对方刺客，不主动开团
   后果：保住己方后排


══════════════════════════════════════════════════════
发育路
══════════════════════════════════════════════════════

0:00 节点
├─ 前提：对方射手在塔前补刀且其位移未交
│  动作：站在小兵身后用普攻消耗，同时补自己这波的兵，消耗完立刻退回，不追求换血
│  后果：对方射手被消耗且无有效还手
├─ 前提：对方射手前压出塔
│  动作：后撤到塔下，用塔下位置补刀
│  后果：不被开
└─ 前提：敌方刺客两名以上且已进入我方半区
   动作：放弃对拼，第一件装备改出抗性鞋或物抗，不做输出装
   后果：被切时存活率提高

2:00 节点
├─ 前提：河道路口有视野
│  动作：与游走一起控河道蟹
│  后果：拿到河道资源
├─ 前提：河道路口无视野
│  动作：不进河道，塔下补刀
│  后果：不被抓
└─ 前提：被抓
   ├─ 前提：雾行千山未使用
   │  动作：交雾行千山穿墙撤离，位移期闪避伤害，落地雾区减速
   │  后果：脱离战场，雾行千山进入 100 秒冷却
   └─ 前提：雾行千山已使用
      动作：交位移或闪现，残血回城
      后果：掉一层经济，保住后续

4:00 节点
├─ 前提：我方下路外塔已破 + 敌方打野不在下路
│  动作：转线到中路吃线磨塔，顺路收己方红区小野
│  后果：单线收益转成中路压力，状态【已转线】
├─ 前提：己方经济被压
│  动作：即使下路外塔未破也去中路吃线补经济
│  后果：补回被压的经济差
├─ 前提：附近有团战且自己已就位
│  动作：过去参团
│  后果：提供团战输出
├─ 前提：我方下路外塔未破
│  动作：继续推线，留一个身位的退路
│  后果：准备转线
└─ 前提：转线途中敌方打野出现在附近
   动作：暂停转线，先做视野
   后果：不做无视野的转线

6:00 节点
├─ 前提：团战中己方前排已与对方前排接触
│  动作：等对方突进与控制交完再输出，集火对方主输出点，不分摊伤害到坦克
│  后果：输出环境成立
├─ 前提：团战中己方前排不在场
│  动作：不进团，带线推塔
│  后果：改为拿塔
└─ 前提：本局己方已阵亡 2 人次以上
   动作：缩塔，减少参团，专心带线刷野补经济
   后果：止损

10:00 节点
├─ 前提：龙坑有我方视野
│  动作：打龙前先占龙坑视野，等前排探完再跟输出
│  后果：安全打龙
├─ 前提：龙坑无我方视野
