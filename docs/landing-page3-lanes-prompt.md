### 结构

每张卡的 DOM 沿用现有 `.card` 同构：

```html
<article class="card">
  <h3>对抗路</h3>
  <p>牵制位，不是输出位。</p>
  <p>……</p>
  <p class="card-note"><a href="/rules?lane=side">进入对抗路库 →</a></p>
</article>
```

- **标题放 `<h3>`**（`.card h3` 已经是 `color: #fff`；`font-weight: 600`、`17px`、字距 `.02em`）。
  如果你要的是「药丸标签也变白」，那指的是 `.card-tag`（现在是 `#9db4ff` 蓝）——
  本次六张卡不使用 `.card-tag`，所以这条指令自然落空。
- **不要 `.card-no`**：六张卡没有 01–06 编号，编号是旧结构的东西。
- **描述用两个 `<p>`**。`.card p { margin: 0 }` 会让两段贴在一起，
  必须补间距，且**只作用于第三页**（通用选择器会撑开第二页和 `.card-note`）：

  ```css
  #page-3 .card p + p { margin-top: 12px; }
  ```

- **末行用 `.card-note`**：它已经是 `margin: auto 0 0`，会自动贴到卡底，
  颜色 `#9db4ff`，正好做链接行。内容是 `<a href="…">进入XX库 →</a>`。
- `.card-note` 里的 `<a>` 要去掉全局的 `text-decoration: underline`（同 `.card-foot a` 的处理），
  改成悬停时颜色变亮。

## 布局：一屏 3.5 个框 + 向右箭头

现有 `.cards` 是三列 grid（`repeat(3, minmax(0, 1fr))`，容器 `max-width: 1180px`），
放不下「3.5 个」。要改成**横向滚动容器**：

```css
/* 容器：露出 3.5 张，第四张半张卡探出来提示「还有」 */
#page-3 .cards {
  display: flex;
  gap: 18px;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  scroll-behavior: smooth;
  padding-right: 64px;          /* 给右缘的箭头让位 */
  scrollbar-width: none;        /* 滚动条藏起来，箭头才是唯一的指引 */
}
#page-3 .cards::-webkit-scrollbar { display: none; }

/* 每张卡的宽度：(1180 - 3×18) / 3.5 ≈ 322px */
#page-3 .card {
  flex: 0 0 calc((100% - 3 * 18px) / 3.5);
  scroll-snap-align: start;
}
```

要点：

- 用 `flex: 0 0 …` 而不是 `flex: 1` —— 后者会把卡撑满，横向滚动就没了。
- 卡高由 `align-items: stretch`（flex 默认）对齐，六张卡等高。
- 第四张卡要露出**约一半**，不是露出一点点，也不是刚好整张。

### 箭头

- 位置：**绝对定位在滚动容器右缘、垂直居中**，压在第四张（半张）卡的右侧。
  视觉上像是「把后面那几张拽过来」。
- 形态：圆形/胶囊底 + 向右的箭头（`→` 或 SVG），半透明白底 + 毛玻璃
  （沿用 `.cta` 的 `backdrop-filter: blur(10px)` 做法），带一圈淡描边。
- 箭头是**真 `<button>`**，`aria-label="下一个"`，可 Tab 聚焦。
- **不能挡住第四张卡上的链接**：按钮本身 `pointer-events: auto`，
  但它的容器要 `pointer-events: none`，否则整片右缘都点不动。
- 滚到末尾时按钮 `disabled` 并降到 `opacity: .3`（否则点了没反应，用户以为坏了）。
- 点击行为：前进一张卡（`scrollBy({ left: 卡宽 + gap, behavior: 'smooth' })`），
  不是翻一屏。

### 键盘与可访问性

- 滚动容器加 `tabindex="0"`、`role="region"`、`aria-label="模式库入口"`，
  让键盘用户能用方向键横向滚动。
- 容器里的每个链接都要能被 Tab 到。
- 触屏用原生惯性滚动即可，不要拦 `touchstart`。

### 断点

- 现有 `1040px` / `680px` 媒体查询要跟着改，否则手机上会露出半张卡被压扁：
  - `≤1040px`：改成露 2.5 张（`flex-basis: calc((100% - 1.5 * 18px) / 2.5)`）
  - `≤680px`：露 1.5 张（`calc((100% - 0.5 * 18px) / 1.5)`）
  - 两种断点下箭头都保留，逻辑不变。

### 降低动态效果

文件里已有 `@media (prefers-reduced-motion: reduce)`，加两条：

```css
@media (prefers-reduced-motion: reduce) {
  #page-3 .cards { scroll-behavior: auto; }
}
```

平滑滚动在这个媒体查询下必须关掉（滚动动画同样会引发前庭不适）。
