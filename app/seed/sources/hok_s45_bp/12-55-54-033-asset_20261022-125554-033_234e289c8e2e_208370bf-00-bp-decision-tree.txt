王者荣耀 S45「月照长安」BP 阶段决策树

版本  S45，2026-09-23 正式服开启
结构  按 BP 决策环节分节点，每个节点按「前提 / 动作 / 后果」分叉
日期  2026-10-21


━━━ 全局前提 ━━━

一、BP 在这局里是什么位置
  BP 决定三件事：对线期哪几条线能拿到线权；队伍有没有开团、控制、承伤、输出这四样；
  这套阵容的胜利条件是什么。
  钻石以上排位与巅峰赛里，具备明显阵容优势的一方胜率约 68.4%（2026 年 1 月《MOBA 职业赛事
  数据白皮书》引述）；版本前三 Ban 率合计约 71.3%（2026 年 7 月巅峰赛 BP 统计）。
  所以 BP 不是选英雄，是定胜负条件。

二、四个决策环节
  禁用  拆掉不能放的英雄
  一抢  定队伍基调
  二抢  第一个针对窗口
  三抢  阶段一收尾承诺
  阶段二一抢  晚针对窗口，对面已暴露三个 pick
  阶段二末选  最后反手位

三、禁用的三类目标（教练江南，官网）
  对方擅长、且己方难以应对的英雄
  放出来后能强行改变打法的英雄
  优先 ban 的根本目的，是让 pick 阶段有机会选出己方擅长的英雄或体系

四、禁用的四类目标（队长模式通用口径）
  硬 counter 自己计划体系的英雄
  能解决自己某个具体短板的英雄
  版本定义级、80% 会被先抢的英雄
  绝活哥的本命（仅在值得花 ban 位时才用）

五、不该 ban 的三类
  对方的本命——没想清楚它是否真的克制自己
  随大流的 tier-1——因为别人 ban 你也 ban
  自己不理解的英雄——盲目 ban 对对方零成本

六、2-2 法则（每队 4 个 ban 时的分配）
  2 个针对对方策略（断掉他想做的事）
  2 个针对自己策略（断掉会破坏你的东西）
  配反的结果是：对方丢了本命，但换了一套照样打你的体系

七、选人的两条硬约束（教练江南，官网）
  第一条：先看选手熟练度。不要给选手根本不会或熟练度过低的英雄，ban 得再好也白搭。
  第二条：再看阵容整体协调性与适配性。常见强组合如大乔加公孙离、阿古朵加马超。
  拆不开对方体系时，用「以抢代 ban」。

八、阵容必须包含的四要素
  前排承伤（至少 1 到 2 个能吃伤害的英雄）
  开团点（谁先手，怎么开起来）
  反手保护（对方开团时谁来打断、谁来给 C 位套盾）
  持续输出与爆发（不能全是靠一套技能打伤害的英雄，技能真空期要有人平 A）

九、一楼与末选的职责
  一抢：选容错率高的英雄（硬辅、控制型坦克、多段位移的战士），不选容易被针对的脆皮 C 位
  末选：上帝视角守门员，先看缺什么（开团、反手、AP/AD 伤害），再补；最后针对对方核心输出位

十、摇摆位与信息差
  能打两条以上分路的英雄，一来可以隐藏真实意图，二来让对面猜错该按哪条线针对。
  一轮 pick 看节奏，二轮 pick 才暴露分路与针对关系；一轮就把核心输出全亮出来等于告诉对方「请针对我」。

十一、S45 版本里被改动的英雄（影响 BP 优先级）
  增强  夏侯惇（33 连招倒钩、大招距离 800→900、二段新增 0.5 秒击飞）、牛魔（投掷巨斧）、
        蒙犽、吕布（附魔回复与护盾上调）、少司缘（一技能六片羽刃叠标记）、大乔（一三技能
        持续伤害约 +20%）、王维（新英雄）
  削弱  关羽（一技能三项伤害下调，额外 Ad 占比提高）、李白（二技能改为剑阵内必定闪避）、
        空空儿、达摩、不知火舞
  二次平衡（9 月 30 日）  马超被动层数削弱一层、移速与伤害同步下调，胜率跌破 50%
  装备  暴烈之甲 900→1000、破魔刀 600→700、冰霜冲击与徐行·凛冬 900→950 且冻结延长、
        不死鸟之眼·血统 5%→6.5%、制裁之刃攻速 20%→30% 且回魂重做、怒龙剑盾被动 CD 2→2.5

十二、官方 HoK Camp 2026-10-16 快照的禁用优先级（全球服口径）
  1  梁（游走）4.2% ban 率
  2  大司命（打野）3.5%
  3  东皇太一（游走）2.7%
  4  王维（中路）2.7%
  5  敖隐（发育路）2.5%
  国内服巅峰赛 1350+ 口径：海月 ban 率约 84% 至 89%，是全场最高。
  两种口径不一致的原因：全球服是国际服玩家池，巅峰赛是国内服高分段。

十三、BP 规则的不确定项
  排位征召模式的确切 ban 位数量与先后顺序，未在 S45 官方更新公告中出现。
  队长模式的口径是每队 4 个 ban、共 8 个，pick 5 个（见下文的禁用节点与选人节点）。
  本文件按「决策环节」组织，不依赖具体 ban 位数量。


━━━ 决策树 ━━━

0:00 节点  进入 BP
├─ 前提：双方均为钻石以上排位或巅峰赛
│  动作：先看敌方五个人的预选位与预选英雄，再看己方五个人的预选位
│  动作：把「我要玩什么」放到最后，先定「这套阵容靠什么赢」
│  后果：得到一条可执行的 BP 目标（体系名 + 三个关键英雄），状态【BP 目标已定】
├─ 前提：己方无人预选，或预选互相冲突
│  动作：用信号逐个确认五个人的位置意向，先定分路再谈英雄
│  后果：分路意向确定，状态【分路意向已定】
└─ 前提：低分段（钻石以下）
   动作：不读预选，只按版本强势与阵容四要素选英雄
   动作：一楼不锁脆皮 C 位，把核心输出留给后手
   后果：BP 目标从「体系」降级为「不亏」，状态【BP 目标降级】


禁用阶段节点（阶段一）
├─ 前提：对方预选位中有一个位置是「先手必抢」（版本非 Ban 必选）
│  动作：第一个 ban 位直接处理这个英雄
│  动作：第二个 ban 位补在「自己打不动的体系轴心」上
│  后果：对方最强的那手出不来，状态【先手已压】
├─ 前提：对方三个人的预选英雄指向同一套体系
│  动作：两个 ban 位拆体系，不拆单个英雄
│  动作：拆不开就以抢代 ban，一抢直接拿体系的核心位
│  后果：对方被迫换体系或改变分路，状态【体系已拆】
├─ 前提：己方阵容缺前排
│  动作：留一个 ban 位给对面能开团的强开辅助（东皇太一、张良、鬼谷子）
│  动作：不要在自己缺前排时 ban 掉所有坦边
│  后果：对方开团手段少一层，状态【开团位已封】
├─ 前提：敌方有回复型阵容（蔡文姬、芈月、程咬金一类）
│  动作：ban 位优先给能破续航的（制裁之刃体系、梦魇体系能挂的法师）
│  动作：不要 ban 貂蝉这类需要净化配合的英雄——对面没带净化，ban 掉价值减半
│  后果：对面拖不到后期，状态【续航已破】
└─ 前提：对方某个 ID 的常用英雄里有省标或国标
   动作：只有在 ban 位有余量时才针对这个绝活
   动作：优先 ban 能被自己体系同时针对的英雄，一个 ban 位解决两件事
   后果：绝活被压且不影响自己体系，状态【绝活已压】


选人阶段节点（一抢）
├─ 前提：己方五人都没锁定核心输出
│  动作：一抢拿版本强势且多位置摇摆的英雄
│  动作：不锁射手、法师、野核
│  后果：对方无法预判真实分路与核心，状态【底牌未露】
├─ 前提：己方已有控制型坦克或辅助
│  动作：一抢可以直接锁开团型辅助，把开团点提前定死
│  后果：体系基调成型，状态【开团已定】
├─ 前提：对方突进刺客数量多
│  动作：一抢拿反手（张良、东皇太一、庄周一类），把突进先按住
│  后果：对方刺客进场即被控，状态【突进已反】
└─ 前提：自己只有一个人会玩某个英雄且熟练度最高
   动作：一抢直接给他，不给对面 ban 的机会
   动作：但必须确认这个英雄能让阵容四要素成立
   后果：己方核心拿到且阵容不缺件，状态【核心已锁】


选人阶段节点（二抢）
├─ 前提：对方已暴露两个 pick
│  动作：二抢针对对方暴露的核心（对位克制或位置克制）
│  动作：优先位置克制，它比对位克制持续更久
│  后果：对方有一路或整个体系被解，状态【针对已落】
├─ 前提：对方暴露的是无位移站桩射手
│  动作：拿强突进刺客或战士，切后排
│  后果：对方输出点被威胁，状态【后排被切】
├─ 前提：对方暴露的是依赖技能连招的英雄
│  动作：拿带强控制或沉默的英雄打断其节奏
│  后果：对方连招打不出来，状态【连招已断】
├─ 前提：对方暴露的是回复型阵容
│  动作：拿能挂制裁或梦魇的输出位
│  后果：对面回复被削，状态【回复已削】
└─ 前提：对方暴露的是消耗型阵容
   动作：拿强开团，逼对方在不利位置接团
   后果：对方打不出持续消耗，状态【消耗已破】


选人阶段节点（三抢）
├─ 前提：己方还缺开团点
│  动作：三抢补开团（牛魔、夏侯惇、苏烈、鲁班大师）
│  动作：S45 里牛魔与夏侯惇都被重做，优先考虑这两手
│  后果：四要素齐了，状态【开团已补】
├─ 前提：己方还缺前排承伤
│  动作：三抢补坦（夏侯惇、白起、廉颇、廉颇、庄周）
│  后果：阵容有了盾，状态【前排已补】
├─ 前提：己方还缺远程消耗
│  动作：三抢补法核（沈梦溪、甄姬、小乔）
│  后果：中期有血线压制手段，状态【消耗已补】
├─ 前提：己方阵容完整但对面控制链很足
│  动作：三抢拿解控（狄仁杰、杨戬、云中君一类），把控制链拆开
│  后果：己方不怕对面连控，状态【控制已解】
└─ 前提：对方已经成体系且拆不动
   动作：三抢转为针对体系轴心做处理（拿能克制体系核心的英雄）
   动作：接受这套阵容，改为针对其打法而不是针对其英雄
   后果：对方体系仍成立但被针对，状态【体系被针对】


选人阶段节点（阶段二一抢）
├─ 前提：对方已暴露三个 pick
│  动作：这是最有效的针对窗口，拿能直接解掉对方核心输出的英雄
│  动作：对方拿的是后排输出，就拿切后排的；对方拿的是体系核心，就拿破坏体系的
│  后果：对方核心被解，状态【晚针对已落】
├─ 前提：对方阵容缺少前排
│  动作：拿一个能扛的战士或坦克，让对方打不动你
│  后果：对方开不了团也切不动，状态【对方缺盾】
├─ 前提：对方是后期阵容且已成型
│  动作：拿前期节奏英雄，把比赛节奏拉到前期结束
│  后果：对面还没成型就被打崩，状态【节奏已拉前】
└─ 前提：对方是前期入侵阵容（澜、裴擒虎一类）
   动作：拿偏防守的英雄（能扛、清线快、有视野），把前期野区守住
   后果：对面抓不到人，状态【野区已守】


选人阶段节点（阶段二末选 · 五楼守门员）
├─ 前提：己方阵容还缺一个位置
│  动作：先补缺口，不看对方
│  动作：缺开团补开团，缺反手补反手，缺伤害补伤害
│  后果：五件套凑齐，状态【阵容已齐】
├─ 前提：己方阵容完整
│  动作：拿针对对方核心输出的英雄（终极 counter）
│  动作：对方中单是高爆发刺客，就拿带控制且护盾厚的辅助对位保护；对方上路是长手消耗，就拿强突进的战士压制
│  后果：对方核心被按住，状态【终极反手已落】
├─ 前提：对方五个人都是硬控阵容
│  动作：末选拿庄周或带净化的英雄，把整套控制链解掉
│  后果：对方控制链不成立，状态【控制链已解】
├─ 前提：己方有摇摆位英雄但对面还没识别
│  动作：把摇摆位留到最后一手亮出来
│  后果：对面来不及调整针对，状态【分路未暴露】
└─ 前提：对方最后一手准备反制自己
   动作：末选改成自己阵容里最难被解的那一手
   后果：反制失败，状态【反制已破】


收尾节点  阵容完整性检查
├─ 前提：五个位置各有一名英雄
│  动作：逐条核对四要素——有没有能吃伤害的、有没有开团、对方开团时有没有人能打断、伤害类型是不是全物理或全法术
│  动作：物理与法术伤害要均衡，最好有一手真伤，否则对面的反伤刺甲与魔女斗篷会同时生效
│  后果：阵容成立，状态【四要素齐】
├─ 前提：全队五个输出位
│  动作：改选一个坦克或战士，牺牲输出换存活
│  后果：团战有站得住的人，状态【前排已补】
├─ 前提：全队五个近战或全队五个远程
│  动作：补一个异构位置，避免对面一套控制或一套强开直接融化
│  后果：对面一套打不穿，状态【异构已成】
├─ 前提：己方只有一个惩戒携带者且是脆皮
│  动作：把惩戒给坦边英雄（廉颇、猪八戒一类），由他主控野区资源，辅助全程跟随协防
│  后果：野区不丢，状态【惩戒已归坦】
└─ 前提：己方是双刺客阵容
   动作：开局 2 分钟内完成首波入侵反野，用双惩击效率抢敌方红蓝 BUFF
   动作：中期执行 131 战术——双刺分带边线，三人抱团中路施压
   后果：前期节奏与中期资源同时拿到，状态【双刺已成型】

━━━ 队伍体系与连锁反应 ━━━

体系身份（决定了胜利条件）
  冲脸体系  强开英雄集火对方后排，靠人数差 5 打 3
  消耗体系  远程压血不接团，逼对方先动，靠血线差滚雪球
  拉扯体系  视野加位移一点点磨，拖到双 C 成型
  单带体系  一人带线牵制对方两三人，其余四打资源
  后期体系  前期苟住，过 25 分钟后靠大核接管

五类反制关系
  用控制反机动  克位移型刺客与突进战士
  用反治疗反续航  克吸血与回复体系（制裁、梦魇）
  用强开反消耗  对面远程压血，我方强开逼他们接团
  用反手反强冲  对面全冲脸，我方拉扯与解控
  用刺客反脆皮后排  对面五个脆皮没前排，刺客是提款机

连锁反应（选 A 就要能选 B，选 B 就要能选 C）
  抢强势打野 → 必须配开团辅助 → 为了保辅助进场 → 中路只能是工具人 →
  为了让射手不被放养 → 边路必须抗压
  看因果链而不是看「谁选了谁」。每一步单看都没错，整条链却可能被对面算死。

选人失误的典型形态
  盲目跟风 ban 别人 ban 的英雄
  忽视阵容搭配，五楼补了个脆皮，队友全是脆皮
  迷信版本答案，自己不熟还硬选
  把队友的本命 ban 掉
  一楼锁死容易被针对的核心输出
  一楼不看阵容先选辅助，导致对面成套反手
