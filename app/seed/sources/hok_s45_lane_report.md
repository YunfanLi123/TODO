## 1. 版本底色：三条主线决定了所有分路的打法

在讲分路之前，必须先钉住 S45 的三个全局判断。**这三条不定，分路打法全是错的。**

### 主线一：版本仍是「中野辅」三核驱动，边路与发育路难以自证

这是 S45 最关键、也最反直觉的一点。

- 对抗路被描述为"姥姥不疼舅舅不爱"：**战士装备一直被削弱，成型速度慢**，导致对抗路即便打出优势也很难扩散给队友。
- 发育路**依旧没有 T0 梯队**——资源点（兵线、野区刷新、防御塔）节奏未变，中野辅三人的前期资源仍然碾压射手，射手前期参与感结构性偏低。
- 结论：**边路和发育路的分路玩家，前中期的主要产出不是"打爆对手"，而是"把个人线权转成团队资源"。** 强行 trying to solo carry 是这一版最典型的亏损来源。

### 主线二：视野从"免费信息"变成"可争夺资源"

这是 S45 改动量最大、也最被低估的一块。

**视野精灵优化（A 级·官方公告原文）**：
- 改为在野区**绕圈飞行巡逻**，暴露范围内敌方目标的视野（**隐身英雄不会被暴露**）
- 最多存活 90 秒；被击败后在原地残留最多 10 秒（残留时长 + 已存活时长 ≤ 90 秒）
- **仅可被普攻攻击**，每次普攻扣一格血，共六格；**近战造成的伤害翻倍**
- 被攻击后会**加速逃跑**，脱离战斗后**逐渐恢复血量**

**由此推出的四条操作原则**：

1. **"打视野精灵"本身就是一次视野交易。** 你抬手普攻的动作是可见的，等于用自己的暴露换对方半片野区的透明。近战三下拆完，射手要六下——**打野天然该做这件事，射手/辅助不要做**。
2. **不必打死，赶走就够。** 精灵被打会加速逃跑且脱战回血。目的只是"不让对方拿到这片视野"时，追两下把它撵走就已经达成目标。
3. **路线必须随机化。** 同一套绕后/蹲伏路线连用两次，第二次大概率被照出来。开局的绕行观察（多花几秒）比硬闯划算。
4. **隐身英雄在 S45 是明确的版本红利位。** 不暴露 + 视野精灵巡逻 = 前期反野的容错显著提高。

**视野规则同时改了四条（A 级）**，直接压缩了蹲草的信息差收益：
- 普攻特效**离开草丛就显示**，不再是命中才暴露
- 技能特效改为**命中才暴露**
- 阻挡范围超出草丛时**不再隐形**
- 技能效果触发时，技能视野被正确暴露

**操作含义**：草丛不再是"进去就隐身、出手才现形"的免费视野。埋伏方的收益被压缩，进攻方需要更强的信息铺垫，而防守方的反制空间变大。**"无脑蹲草"这一版是负收益动作。**

### 主线三：雾行千山把"跨地形脱战/进场"变成了常规操作

**赛季限定召唤师技能（A 级）**：朝指定方向冲刺穿越任意长度墙体，途中闪避伤害，路径留下雾气造成减速。**冷却 100 秒，仅当前赛季有效。**

三个可直接映射到分路的推论：

1. **CD 100 秒意味着"不能当闪现用"。** 一局 15 分钟，你能用它做 8-9 次决策，不是每波团都能交。**留给真正的地形决策点**，不要用来赶路。
2. **它改变了地形边界的含义。** 看到一个人隔墙消失，不能默认他已经撤走——野区的墙过去是安全边界，现在不是。**判断一波冲突必须把进场路线和退路一起算进去。**
3. **它同时抬高了"我方后排的生存地板"和"敌方切后排的威胁上限"。** 位移期闪避让进场更难被反应，落地减速雾又给了一层追人手段。这意味着**每一路都要重新评估"我被抓了还能不能活"**，而不是沿用旧版本的裸输出习惯。

> 附：S45 新增**合作类技能意图可见**（A 级）——刘邦传送、哪吒锁定目标时，目标头顶会显示英雄头像（仅友方可见）。配合成本下降，跨路支援的"发起—响应"链条变短，这是支援判断可以更激进的基础设施。

## 2. 打野：整局的节奏轴心

### 前期（0-4 分钟）：第一目标是"到 4 级且保住野区"，不是抓人

**版本压力**：策划持续在降低打野的"话语权"——防御塔免伤、空间之灵等调整都在**提升抓人成本**，前 5 分钟能做的事情非常有限。

**前期操作主线（三条，按优先级）**：

1. **清完自己野区升 4 级 > 任何一次 gank。**
   - 漏野导致的等级滞后，会让你失去和对方打野对拼的资格——这是连锁亏损，不是单点亏损。
   - 只有在**敌方深压线 + 我方线上血量状态良好 + 我方控制链已就绪 + 敌方关键召唤师技能进入真空期**这四个条件同时满足时，才放弃剩余小野直接绕后。四个条件缺一个，继续刷。

2. **视野精灵当作开局的第一件"装备"来处理。**
   - 顺风局：直接清掉，一路推过去（近战三下，效率最高）。
   - 逆风局：**别碰，绕开走。** 为了清一个视野精灵把自己送进包围，是典型的亏损交易。
   - 开局建议：红/蓝开之后**不要直奔目标路**，先绕一圈看精灵巡逻范围再决定从哪个口子进。多花几秒，换不被提前发现。

3. **支援路线的重心从"河道"往"野区线"迁移，但反直觉地河道更安全。**
   - 野区有精灵巡逻 → 对手注意力也在野区 → 河道反而成为信息洼地。
   - 结论：**有精灵在的野区入口是高危区，无精灵覆盖的河道是相对安全区。** 跑图前先判断精灵在哪。

**前期避坑**：自家野区明显有被入侵风险时**立刻回防**，不要有抓人想法；辅助不跟时**不要强行越塔**。

### 中期（4-10 分钟）：后手进场 + 控龙优先于人头

**职业赛场最一致的一条共识：打野不先手开团。**

高机动性打野（澜、镜、曜一类）的强度完全建立在"能打满伤害且不被控"的前提上。一旦先手吃到控制，再高的伤害也打不出来，直接变废。职业局里这类打野绝大多数是**等对面关键硬控交完后进场收割**。

**具体判断框架**：
- 进场前先算清三件事：**敌方控制是否已交 / 闪现治疗是否在真空 / 我方前排是否已经站位到位**。三件事不齐，宁可再等 10 秒打第二轮。
- **"打龙"这件事本身正在变难**：视野精灵能看到龙坑范围，抢龙的一方更容易被发现。抢龙从"偷偷开"变成了**"抢时间差"**——你必须在对方视野盲区的窗口内把龙打掉，慢一点就被包。

**控龙优先级（B 级·梯度榜与多源一致）**：
- **暴君增益是团队前期扩大优势的命脉，能拿就尽量拿。**
- **主宰（暗影，10 分钟节点）是分水岭。** 经济领先明显时可直接抱团逼团 → 拿下主宰 → 用主宰先锋拆边路二塔。
- **主宰在己方状态不好时完全可以放。** 为了抢主宰全员掉点被一波翻盘的比率，远高于放弃主宰的损失。
- **推塔的整体收益 > 反一组野怪。** 能推塔先推塔，推完再进敌方野区。

**"控龙 vs 人头"这个取舍的本质**：人头是**一次性结算**，龙和塔是**持续增益**。这一版的地图机制改动（视野精灵）进一步放大了这一点——因为视野和地形控制的价值在上升，而人头并没有跟着涨。

**野区被入侵时的"守还是放"决策框架（这条值得单独记）**：

不要算"我的蓝没了，我亏了"。要算 **资源 ÷ 投入时间**：

- 对面**一个人顺路摸进来** → 几乎没有额外成本 → **不能白送，必须守**。
- 对面**中野辅三个人跑了半张地图** → 问一句"地图另外半边现在谁在" → 他们留下的空档就是你该拿的东西 → **让，把资源换成另一侧的塔和线**。
- **必须守的唯一理由**：这片资源一旦失守，会让下一分钟整张地图一起失去主动权。比如己方核心极度依赖某个 buff、下一条关键资源马上刷新、且防守位已经提前站好——这时候 buff 区本身就是下一场团战的前哨阵地。
- **一定别硬顶的情况**：对方多人先落位 + 自家兵线没处理 + 关键技能不齐 + 地图另一侧还有明确资源可交换。这时候进去拼惩击，是把选择题做成了赌博题。

### 后期（10 分钟后）：控资源 + 抓落单，不接 5v5

- **顺风**：把经济差**转成视野差**——转线压塔、控龙、反野。经济领先只是数字，视野领先才是能滚雪球的形态。赢团之后不要逛街，**有兵线就压高地**。
- **逆风**：
  - 重点控暴君、主宰，抓对面**带线落单**的人，不要强行接 5v5。
  - 对面抱团压中路高地时，**不要跟着队友在塔下硬守**——绕到敌方身后断掉最远的那波边路兵线，逼迫对方回人清兵，直接缓解高地压力。
  - 完全退守高地时，站**高地塔侧后方的草丛**，不露头，等兵线进塔再配合清线。
  - 出装顺序：**打野刀先升二级，优先补防御装备，不要先做输出装**，避免被直接秒掉。
- **全局纪律**：逆风严禁脸探草丛；**抓人失败后必须立刻回头刷野或换路，严禁在原地发呆或试图蹲守补救**。

## 3. 中路：整局的节奏发动机

中路是**唯一能主动前往任意一条边路**的位置。这个几何事实决定了中路在 S45 的操作主线不是"中路对线",而是**"用清线速度兑换全图支援权"**。

### 前期（0-4 分钟）：清线速度就是支援权

1. **第一优先级是把线推出去，而不是把对手打残。** 中路的血线优势是**流动的**——一旦被打回家，节奏就断了。中路选手的核心动作是"清完线就走",不是"在线上多A两下"。
2. **河道视野从前期就要开始做。** 二级抓中是这一版最经典的节奏点，而草丛位置的调整（**D 级·体验服整理，未在正式公告中确认**：中路靠塔侧草丛向河道方向移动）意味着**抓中方的进攻门槛提高、必须更靠近河道**。防守方只要河道有视野，就能提前发现。
   > 操作含义：无论这个改动是否落地，**中路前期主动做河道视野都是净收益动作**——它同时防住了草丛蹲伏和精灵巡逻两条信息路径。
3. **主攻属性规则被优化（A 级）**：大部分英雄改为**根据自身技能加成类型确定主攻击属性**（艾琳、梦奇、司空震有特殊判定）。这条对中路最实际的影响是——**出装的"摇摆"空间变小了**，你可以更早锁定物理/法术向，节省掉前期反复试错的决策成本。

### 中期（4-10 分钟）：压缩对方转线空间

这一版中路的标志性动作是**主动压对方中塔**。

- 线权型中路（长手清线、法球/减速类）的价值不在单杀，而在于**持续压制中路一塔，把对方的转线路径挤没**。对方无法转线支援边路，中野辅的联动就被拆散。
- **抢完线立刻跟打野游走。** 不要死守塔下清线——塔下清线是最浪费中路边际效应的动作。
- 游走方向优先级：**对方打野位置不明 → 跟打野**；**己方边路有线权 → 去边路扩大优势**。

### 中期团战：中路是分割位，不是输出位

**职业赛场共识（多源交叉一致）**：
- 中路法师在 S45 的主要团战职责是**分割战场 / 隔离核心输出点**，而不是追求输出量。大招尽量框住多人、把敌方核心 C 位拉进单独区域，制造以多打少。
- **大招真空期的站位是这一版中路最致命的细节。** 隔离型大招（比如把敌人拉进幻境）本身是双刃剑：成功则制造人数优势，**结束瞬间就是自身最脆的时刻**。职业选手的做法是大招结束后**立刻后撤**，不贪输出、不贪平A。
- **对多突脸阵容要主动换思路。** 当敌方突进数量多时，脆皮中单的生存环境会急剧恶化，此时应当退到远程消耗的思路（长手poke、控场而非爆发），用血线压制替队友创造输出环境，而不是硬拼爆发。

### 后期（10 分钟后）：中路变成"视野和先手"位置

- 中路后期的核心动作是**跟着兵线和龙坑走**，而不是守中路那几棵树。中路二塔是**换取龙坑控制权的筹码**，拆塔的目的在于压缩对方打野的防守半径。
- 中路后期的团战定位：**先手/分割 + 保护己方后排开团后的输出窗口**。
- **主攻属性规则在这一阶段的意义放大**：后期对面坦装普遍回暖（前文装备部分），中路的伤害构成需要提前规划好"打谁"，而不是"能打谁就打谁"。

## 4. 对抗路：牵制位，不是输出位

**这一版的对抗路，必须先接受一个定位事实：你是牵制资源，不是输出资源。**

对抗路选手在前中期花了最多力气做的事（单杀对手、打出优势），如果没有转成**塔 / 龙 / 视野 / 队友的进场空间**，对胜率的贡献接近于零。

### 前期（0-4 分钟）：线权 > 人头

1. **第一目标是稳线权，不是蹲单杀。** 职业赛场和高端排位一致的判断是：**单杀三次不如控下一条龙带来的经济差大。** 前期把优势换成河道资源、传送阵视野、龙坑站位，价值远高于多一个人头。
2. **抢完线的动作是"往河道和龙坑靠"，不是"回线上继续压"。** 压线的收益在对方打野出现时瞬间归零。
3. **草丛位置调整（D 级·未确认）**：对抗路一塔旁侧草丛向塔方向收缩，**一级蹲草抢线拿一血的经典套路被弱化**——草丛更靠近塔，出门探一下就能发现。无论是否落地，**一级主动做草丛视野检查**都是低成本高收益的防御动作。
4. **战边与坦边的前期动作完全不同**（这是分路内部的第一个分叉）：
   - **战边**：前期目标偏向"建立单点击杀威胁 + 保持血量优势"，但因为**战士装备成型慢**，前期过度追求击杀的收益被削弱得更明显。**前期少换血、多保持状态。**
   - **坦边**：前期目标偏向"扛线 + 观察野区 + 能支援就支援"。坦边的价值在**中期团战**，前期不必追求压制。

### 中期（4-10 分钟）：单带牵制的正确用法

单带的价值在于**制造以多打少**，不在于"把塔偷了"。判断标准很清楚：

- **对方来一个人 → 打他。** 击杀或逼退，直接获得正面优势。
- **对方来两个人 → 通知队友开龙或抓其他路。** 你已经完成了牵制职责，不要恋战。
- **对方来三个人 → 跑。** 不要为了"操作一下"送掉单带点。

**中期参团 vs 带线的取舍框架**：
- **带线的收益是可预期的**（塔的经济是确定的）。
- **参团的收益是不确定的，但上限高**（团赢了能顺势推掉更多塔）。
- 因此：**敌方五人位置集中且己方打野就位 → 参团；敌方五人分散在带线 → 带线**。判断依据是"**敌方五人是否已经抱团**"，而不是"我这波兵线好不好"。

**坦边的职业共识（多源交叉一致，值得单列）**：
功能型坦边在对抗路最大的误区是**把自己当战边去切 C 位**。单排情况下，坦边的正确定位是**稳住阵线、保护己方 C 位**，胜率会高得多。原因很直接：职业队的五人配合你复制不了，但"扛在前面让队友有输出环境"这件事在单排里同样成立。

### 后期（10 分钟后）：单带还是抱团，是一道二选一

- **己方阵容适合分推 → 继续单带牵制。** S45 的视野精灵与跨地形机动让"被抓单带"的惩罚变重，但也让"你不来就掉塔"的牵制力变强——**这是 S45 单带价值的真实来源**。
- **需要你回防保护后排 → 留在队伍中间**，用你的控制/威胁技能**威慑**对方刺客，而不是主动去开团。
- **对抗路后期的核心能力是"让对方必须派人来处理你"**。只要对方必须回一个人，你这边就是四打五，这个交换本身就是收益。
- **注意分带的时间窗**：视野精灵最长存在 90 秒且被击败后还会残留最多 10 秒视野。深推的边线往往已经在对方视野覆盖范围内，**不要在没有清过视野的情况下走最远的边线**。

## 5. 发育路：经济位，后期唯一的胜负手

发育路的操作主线在这一版异常清晰：**前期少死，中期转线，后期不贪。**

### 前期（0-4 分钟）：唯一任务是"活到 4 级之后"

版本现实：**发育路依旧没有 T0 梯队，资源点节奏未变，中野辅三人的前期资源碾压射手。** 这意味着发育路前期投入战斗的期望收益是负的。

1. **补刀优先于推线。** 小兵最后一击自己拿，补刀经济更高。但补刀 ≠ 无脑推线——**兵线进塔时是最容易被抓的窗口**。
2. **"敌人消失"= 立刻后撤。** 敌方中单/辅助/打野任意一个从小地图消失，都应该视为撤退信号，而不是"他可能只是回城"。
3. **脸探草丛是硬性禁止动作。** 没有视野时用技能试探探草，不要用身体探。这一版视野规则改动后，草丛收益已经压缩，"试探"的动作本身也会暴露你。
4. **劣势时的正确操作是"学会放塔"。** 多人越塔风险高，**死一次亏两波兵，远比丢一座塔损失更大**。对线崩了就在塔下抗压，把节奏交给中野。
5. **河道草丛位置调整（D 级·未确认）**：发育路靠河道侧草丛向墙体方向移动，**前期被抓死的概率降低**。但这不意味着可以放松——你需要主动去那个位置做视野，把它从"对方藏身处"变成"我的观察点"。

**雾行千山对发育路的特殊意义**：它给了"无位移射手"一个跨地形的自保与追击手段，**压缩了呆射和位移射手之间的生存差距**。但请注意第三条主线的推论——CD 100 秒，且它**不是射手专属**，战士和坦克也能用来开团，甚至因为护盾与最大生命相关，他们越拖后期越肉。

**所以发育路的前期判断标准是**：不要因为"我有了雾行千山"就敢往前压。对面带雾行千山的战边，威胁等级和以前完全不同。

### 中期（4-10 分钟）：一塔之后必须转线

这是发育路**最重要的一条操作主线**，也是最常被违反的一条。

1. **死守一路补十分钟兵，是这一版发育路最差解。** 你在补的每一波兵的价值，都低于你参与一次龙团或帮中路拆塔的收益。
2. **标准转线动作**：清完下路兵线 → 确认安全 → 转中路吃线/磨中塔 → 顺路收己方红区小野 → 最大化经济转化。
3. **中期团战的三条铁律**：
   - **不第一个进场。** 等敌方关键突进和控制交完再输出。
   - **只打离你最近的目标。** 不要越过前排去切后排——这一版坦装集体回暖（暴烈之甲、破魔刀、冰霜冲击全部上调生命值），穿前排打坦克的效率已经明显下降。
   - **资源优先级：防御塔 > 暴君 > 人头。** 有优势优先推塔，用塔的优势扩大地图视野。
4. **出装不要固定一套。** 这一版主攻属性规则优化后，摇摆空间变小，但**针对性调整更重要**：对面控制多换抵抗类，对面物理刺客多补防御装。**不要死憋纯输出。**

### 后期（10 分钟后）：站位就是你的输出量

1. **站位背靠己方前排，站在队伍侧后方。** 敌方刺客没露头绝不往前冲。
2. **输出逻辑**：优先处理突进你的敌人，不要执着于追残血。刺客一旦露面，**第一时间拉开距离**。
3. **龙团谨慎**：打龙前先保证视野，不要单独走河道，等前排探完视野再跟输出。S45 龙坑相关地形调整（D 级未确认）提到出口拓宽与坑外草丛，若已落地，**坑内蹲伏位失效，抢龙方也有对称的反制位**——两边都要重新适应。
4. **赢团必推塔。** 打赢团战不要集体原地逛街，有兵线就压高地，快速终结，避免拖到后期被翻盘。

### 发育路的长期纪律（决定段位上限的三条）

1. **死亡控制 > 人头数。** 把场均死亡压到 3 次以内——每次阵亡都同时丢掉经济、塔和龙，这是发育路掉分的最大单一原因。
2. **止损意识**：连续被抓、对线崩盘，就减少参团，专心带线刷野补经济，**不要强行接团继续送**。
3. **复盘只看一件事**：我这次死亡是不是因为压线、探草、站位靠前。改掉一条坏习惯，收益大于多练一套连招。

## 6. 游走（辅助）：信息位 + 开团位

### 前期（0-4 分钟）：跟着打野，别跟着射手

1. **前期的游走位核心动作是"提供视野 + 建立信息差"，不是"保护射手"。**
   - 视野精灵改版后，**视野成为可以主动去争夺的资源**。游走位是唯一一个在前期有时间和机动性去做这件事的位置。
   - 顺风：配合打野清精灵，把对方野区做成透明。
   - 逆风：优先河道和龙坑的精灵，让对方不敢靠近。
2. **辅助不要去打视野精灵。** 精灵六格血、只吃普攻，辅助近战也只有翻倍伤害（两格），要三下，且站桩时间极长。这件事**交给近战打野**做，效率差两倍以上。
3. **牛魔的一技能在 S45 被重做（A 级·官方公告）**：改为**朝指定方向投掷巨斧**，命中造成伤害 + 击退 + 减少物理防御；可拾取巨斧回旋斩击造成等量伤害，未拾取则 2.5 秒后自动召回并把路径上的敌人**拉回**。同时二/三技能改为**附带敌方最大生命百分比伤害**的模型。
   - **操作含义**：牛魔从"憨憨保镖"变成了**可控的拉扯型开团**——巨斧可以拾取可以召回，等于开团位置由自己决定而不是由走位决定。**"斧头扔出去 → 收回 → 大招召回"这组合成了新的开团链条**，但二/三技能的基础数值被下调、改为按最大生命百分比结算，**坦度不再来自固定数值，抗性收益下降**——这改变了辅助的装备优先级排序。

### 中期（4-10 分钟后）：三件事轮换，不要死守

游走位最容易犯的错误是**5 分钟后仍然死守发育路当 C 位的连体婴儿**。

正确的操作模式是**三件事轮换**：
1. **视野** —— 清视野精灵、布河道眼、探敌方草丛、给龙坑做视野
2. **开团** —— 在对方阵型最完整的时候主动开，而不是被动等对方开
3. **保 C** —— C 位进入危险窗口时的贴身保护

**轮换的判断依据不是时间，而是地图事件**：龙要刷了 → 视野为主；对面五人抱团 → 开团为主；己方 C 位在对方强开射程内 → 保 C 为主。

**中期辅助的核心产出是"让队友可以做危险动作"。** 一条被对方抓死的边路，往往不是边路不会玩，是辅助的视野没到位。对抗路和发育路的死亡率，很大一部分是游走位的责任范围。

### 后期（10 分钟后）：开团时机 vs 保护后排

1. **开团时机 > 开团成功率。** 这一版视野规则压缩了信息差，开团方的容错变低。**在对方关键控制没交之前开团，成功率会显著下降。**
2. **优先开团**而不是优先保护：当对方有一个必须死的核心输出点，且己方控制链完整时，主动开团比被动反打收益高。
3. **优先保护**而不是强开：当己方后排已经站位失误、被对方切入了，**这时候你的最优动作是把人救回来，而不是自己冲上去换一个。**
4. **龙坑团的视野布控是辅助后期的核心任务**：打龙前把龙坑周围的精灵位置和敌方视野搞清楚，**不要一个人进河道**。

## 7. 通用决策速查表

### 三条时间窗的通用原则

| 时间窗 | 全队共同的第一优先级 | 常见的亏损动作 |
|---|---|---|
| 0-4 分钟 | 到 4 级、保住野区/血量、建立信息差 | 漏野换 gank、脸探草丛、无视野压线 |
| 4-10 分钟 | 控龙 > 转线推塔 > 人头 | 追残血、无兵线打架、先手开团吃全套控制 |
| 10 分钟后 | 视野差 + 主宰/暴君 + 赢团即推塔 | 原地逛街、逆风硬接 5v5、深推无视野边线 |

### 全局高频亏损动作清单（S45 版）

1. 无视野脸探草丛（视野规则已改，收益压缩）
2. 为清视野精灵把自己送进包围（顺风才做，逆风绕开）
3. 兵线进塔时还在贪最后一下补刀
4. "敌人消失"后继续往前压线
5. 团战第一个进场吃满控制
6. 赢团之后不去推塔
7. 越前排去打后排（这一版坦装回暖，这条的死亡率显著上升）
8. 抓人失败后原地发呆或试图蹲守补救
9. 逆风硬接 5v5
10. 劣势局裸全输出，没留保命装

### 装备改动对分路决策的实际影响（A 级·官方公告）

这几条会直接改变"该不该出这个装备"的判断，值得单独记住：

- **暴烈之甲 生命值 900 → 1000** —— 前排更硬，射手穿前排的效率进一步下降。
- **破魔刀 生命值 600 → 700** —— 法坦性价比提升。
- **冰霜冲击 / 徐行·凛冬 生命值 900 → 950**，主动冻结 0.75 秒 → 2/3 秒 —— 控制时长提升。
- **不死鸟之眼·血统** 损失 10% 生命提升回复 5% → 6.5% —— 坦克/战士的续航上调。
- **制裁之刃**：攻速 20% → 30%，物理攻击 100 → 75，**回魂重做**（从"低于 30% 生命时 5 秒回复"改为"低于 40% 生命时 1 秒回复 + 普攻持续回复，远程翻倍"）。
  - **操作含义**：制裁之刃从"一次性救命装"变成了"可滚雪球的持续输出装"，尤其利好需要站桩输出的战士。这是 S45 少数几个**真的改变了单带/单挑逻辑**的装备改动。
- **怒龙剑盾 被动冷却 2 → 2.5 秒** —— 略微削弱高频触发的法坦。

**结论**：坦装集体回暖 → **中期团的性质从"冲脸打穿前排"转向"找后排 + 打控制窗口"**。这一条会同时影响发育路、对抗路和游走位三方的操作模式。
